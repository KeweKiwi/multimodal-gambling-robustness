# Proposed manuscript availability statement

**For author review; use only once the approved files are actually public.**

> The original Indonesian Gambling Multimodal Dataset is available on Hugging Face at https://huggingface.co/datasets/0xRafie/indonesian-gambling-multimodal-dataset. The FINAL V2 research source, exact train/validation/test split identifiers, saved test predictions, and evaluation outputs supporting this study are available at https://github.com/KeweKiwi/multimodal-gambling-robustness. The repository documents the audited dataset revision, dependency versions observed in the research workspace, and instructions for reproducing the evaluation from saved predictions or regenerating embeddings and retraining the models. Raw images, full captions, embeddings and trained checkpoints are not redistributed. Encoder revision pins and a complete experiment-time environment lock were not recorded; the repository states the resulting limits on bit-exact retraining.

The split files preserve identifiers and row order without redistributing captions. Necessary original captions and images come from the source dataset. After publication, add the actual approved commit or release tag to the manuscript statement if desired. Do not insert a release hash or archival DOI before one exists.
